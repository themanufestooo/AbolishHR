# Resume Guide

One page. Built for ATS (the software employers use to scan resumes). Every claim traceable to your verified profile.

## Format rules

- **One page.** If it doesn't fit, cut the least relevant — never shrink the truth.
- **Simple layout.** No tables, text boxes, graphics, or unusual fonts. ATS software misreads them.
- Standard sections, in this order: Name + contact → Summary (2–3 lines) → Experience (reverse chronological) → Skills → Education.
- File name: `[LAST NAME]_[FIRST NAME]_Resume_[COMPANY]_[ROLE].pdf` — so each version is traceable.

## Content rules

- Every bullet describes something you actually did. No invented metrics, no borrowed achievements.
- Lead with strong verbs: managed, built, served, coordinated, repaired, delivered.
- Measurable results go first in each bullet ("Served 40+ customers daily" beats "Responsible for customer service").
- Translate, don't inflate. "Ran a household of five on a tight budget" can become scheduling and budgeting experience — but only with your approval of the wording.
- Tailor per role: reorder bullets and emphasize the experience that matches this employer's needs. The facts don't change; the spotlight does.

## Version binding

Every application gets its own resume version, recorded in the tracker:

| Application | Resume version | Date |
|---|---|---|
| [COMPANY] — [ROLE] | Resume v[N] | [DATE] |

If an employer asks about your resume later, you can pull up exactly what they received.

## Before first use

Read your draft resume line by line. Approve every factual claim. If a bullet makes you uncomfortable, cut it or reword it — a resume you're not confident defending hurts you in interviews.
